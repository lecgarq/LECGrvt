# Phase 2.5 — Validation Strategy

> Per-phase validation contract. CONTEXT.md §E locks the test bar to **manual Revit checklist only** for this phase — no automated harness is in scope. This document records the manual sampling cadence and per-requirement fixtures so plans can reference it.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Manual Revit session (no automated harness) |
| **Config file** | none |
| **Quick run command** | Open Revit → load fixture project → run command under test |
| **Full suite command** | Single end-to-end Revit session covering all REQ fixtures |
| **Estimated runtime** | ~10 min per plan (manual) |

---

## Sampling Rate

- **After every task commit:** Build (`dotnet build`) — code must compile.
- **After every plan:** Manual Revit smoke per the per-requirement fixtures below for that plan's REQ.
- **Before `/gsd:verify-work`:** Full manual checklist green on Spanish-locale Revit (REQ-08 dictates locale).
- **Max feedback latency:** Compile time only between commits; manual sweep at plan boundaries.
