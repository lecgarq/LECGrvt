    1. In `src/ViewModels/Components/SelectionViewModel.cs`:
       - Add `using LECG.Services;` (for ElementLabelService).
       - Add `public ObservableCollection<ElementRowViewModel> RowItems { get; } = new();`.
       - Add helper:
         ```csharp
         public void SetSelectionRows(IEnumerable<Reference>? refs, Document? doc)
         {
             RowItems.Clear();
             if (refs == null || doc == null) return;
             foreach (var r in refs)
             {
                 Element? el = doc.GetElement(r);
                 if (el == null) continue;
                 var (name, category) = ElementLabelService.GetLabels(el);
                 RowItems.Add(new ElementRowViewModel
                 {
                     Id = el.Id.Value,
                     Name = name,
                     Category = category,
                     Type = el.GetType().Name,
                     Status = "",
                     IsChecked = true
                 });
             }
         }
         ```
       - Wire `SetSelectionRows` into every existing setter / mutator that updates the underlying `IList<Reference>` selection. Audit for: `SetSelection`, `SetReference`, `Clear`, `AddReference`, `ReplaceReferences`, etc. Each must call `SetSelectionRows` after mutation. (Names may differ — read the file end-to-end.)
       - Use the WPF Dispatcher pattern (RESEARCH §Pitfall 3) IF mutations can come from a non-UI thread (Revit event handler). Wrap with `Application.Current?.Dispatcher.Invoke(...)` if that's the case in the existing codebase.

    2. In `src/Views/Components/SelectionControl.xaml`: append an `<controls:ElementGridControl RowItems="{Binding RowItems}" Height="160" Margin="0,8,0,0"/>` below the existing "N elements selected" text. This gives all consuming Views the grid for free without per-View XAML edits.

       If the SelectionControl layout is too constrained (e.g., embedded inside a popup), instead leave SelectionControl unchanged and embed `ElementGridControl` per-View in Task 2.

       Document the chosen approach in 03-08-SUMMARY.md.
