## Milestone Summary

**Decimal Phases:**

- Phase 2.5: Silent Data-Loss Hotfixes (inserted after Phase 2 for urgent 5-plugin audit findings; REQ-08/09/10)

**Key Decisions:**

- SubTransaction per parameter in `MoveParamsToGroup` — one failed move logs and continues rather than aborting all params
- Remove `GetGroupTypeId()` post-call check from `TrySetParameterGroup` — in-transaction read is a false-negative; group persistence verified post-reload
- `BuiltInParameter.TEXT_ALIGNMENT` (not `TEXT_ALIGN_HORZ`) for type-level horizontal alignment on `TextNote` — `TEXT_ALIGN_HORZ` is instance-level
- Refuse-all (not partial-success) for mixed batches in `SwapInstances` — any unsupported instance aborts entire swap (REQ-09)
- LocationCurve / hosted / face-hosted transplant placement deferred to v1.2 — REQ-09 refuse-only scope
- Face-hosted preservation deferred to v1.2 — `FamilyInstanceData` lacks HostFace capture; Branch 3 free-standing fallback documented as known regression (REQ-10)
- `FindReplacementSymbolByName` ordinal exact-name match; no first-symbol fallback — missing type name throws before delete (REQ-10)
- `ElementRowViewModel` uses `[ObservableProperty]` only for `IsChecked`; identity/display fields are plain auto-properties (set once at row creation)
- `ElementLabelService` placed in `src/Services` (`LECG.csproj`) — `GetLabels(Element)` requires Revit API; pure-string overload supports unit-testing
- Locale-safe category labels via `LabelUtils.GetLabelFor((BuiltInCategory)cat.Id.Value)` with explicit null-check (NOT `element.Category?.Id.Value` — short-circuits to nullable long which mis-casts)
- Skip-gated RED tests with reason strings naming the implementing plan — keeps suite green and gives plan authors a greppable flip-point (Wave-0 pattern reused by Phases 03/04/05)
- One non-skipped anchor test per fixture ensures `dotnet test --filter` discovers it even when all behavioural tests are skip-gated
- Canonical local build command while Revit is open: `dotnet build LECG.Tests/LECG.Tests.csproj -p:SkipRevitDeploy=true` (bypasses MSB3027 file-lock on ProgramData addins folder)
- ICollectionView ownership lives on the ViewModel, not the control — each screen owns its own sort/filter semantics
- SelectionControl Path A: embed ElementGridControl in `SelectionControl.xaml` — eliminates 8 per-View XAML edits and guarantees grid consistency across selection-backed screens
- `IFormulaUpdateService` injected as last constructor parameter — MS DI resolves automatically; reflection used for ctor tests (Castle DynamicProxy cannot proxy without RevitAPI.dll)
- `ExecuteDimensionReassignments` accepts `List<Action>` not `List<Dimension>` — decouples helper from Revit API
- Manual Revit verification trust-based for Phases 4/5 (user approved 2026-05-10) — helpers proven via 5 GREEN unit tests; live observation deferred where test fixture unavailable
- BuildProgressSequence Option A — production uses direct arithmetic; helper exists for unit-test verifiability only
