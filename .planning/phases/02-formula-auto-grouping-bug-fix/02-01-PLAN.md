    **Fix 1 — MoveParamsToGroup (line ~485): Replace all-or-nothing throw with per-parameter SubTransaction.**

    Current structure inside the foreach loop (lines ~506-513):
    ```csharp
    if (!TryMoveParameterToGroup(..., out string? error))
    {
        // look up current group, then:
        throw new UnsupportedGroupChangeException(...);
    }
    changed++;
    ```

    Replace with:
    ```csharp
    using (var sub = new SubTransaction(familyDoc))
    {
        sub.Start();
        if (TryMoveParameterToGroup(familyDoc, fm, currentParameter, targetGroup, out string? error))
        {
            sub.Commit();
            changed++;
        }
        else
        {
            sub.RollBack();
            Log($"  Skipped '{name}': {error ?? "move failed"}");
        }
    }
    ```

    Remove the block that looked up currentGroupLabel and built the UnsupportedGroupChangeException message — it is no longer needed. The outer catch (UnsupportedGroupChangeException) in ExecuteInFamilyDocument and ProcessProjectFamily remains in place for now (it will be dead code after this change but removing it is a cleanup for later).

    **Fix 2 — TrySetParameterGroup (line ~605): Remove in-transaction GetGroupTypeId() persistence check.**

    Current lines 623-627 (after the SetGroupTypeId try/catch):
    ```csharp
    if (parameter.Definition.GetGroupTypeId() != targetGroup)
    {
        error = "group change did not persist";
        return false;
    }
    ```
    Delete these five lines entirely. The method should return `true` with `error = null` immediately after the try/catch succeeds.

    **Fix 3 — TrySetFormula (line ~806): Add EnsureCurrentType guard.**

    Before the line `familyManager.SetFormula(parameter, formula);`, insert:
    ```csharp
    if (!EnsureCurrentType(familyManager))
    ```

    ```csharp
    private static bool EnsureCurrentType(FamilyManager fm)

        if (fm.CurrentType != null) return true;
        foreach (FamilyType ft in fm.Types)
        {
            return TrySetCurrentType(fm, ft);

        return false; // no types exist

    ```
