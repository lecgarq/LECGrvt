# Changelog

All notable changes to the LECG Revit 2026 add-in.

Versions come from `VersionPrefix` in `Directory.Build.props`. Maintained by `/lecg-ship`.

## [Unreleased]

### Added
- `docs/ai/revit-api/` — greppable index of the Revit 2026.4.10 API surface (33,091 members, 2,670 types) plus `SEMANTICS.md`, generated by `scripts/revit-api-index`

### Changed
- Replaced the GSD workflow plugin with six `lecg-*` skills in `.claude/skills/`
- `AGENTS.md` now specifies `dotnet build -p:SkipRevitDeploy=true`, which does not overwrite the live Revit add-in folder

### Fixed
- **LECG no longer restyles other add-ins.** `LecgTheme.xaml` was merged into `Application.Current.Resources` — Revit's own WPF application — so its implicit styles for `Button`, `TextBox`, `ComboBox`, `RadioButton`, `ProgressBar`, `TreeView` and `TreeViewItem` applied to Revit's dialogs and every other loaded add-in. The theme is now merged per-window in `LecgWindow`; `App` only ensures a WPF `Application` exists.
- `LECG.csproj` now excludes `scripts/**/*.cs` from compilation, matching the existing `tools/**` exclusion

### Removed
- `PROJECT_RULES.md`, `adapters/`, `docs/runbook.md`, `GSD-STYLE.md`, and the unreferenced `VERSION` file (held GSD's version, 1.5.0) — all GSD artifacts
