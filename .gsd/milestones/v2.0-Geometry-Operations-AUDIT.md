## Concerns
- **Geometry Service Fragility**: Direct reliance on specific `SlabShapeEditor` behavior for Toposolids in 2026 might break if future hotfixes change the coordinate system (e.g. `Toposolid.Create` vs `Project Points`).
- **Planar Projection Fallback**: `FixPointsService` falls back to averaging if neighbors are collinear. While rare on slabs, it might produce minor artifacts on narrow edges.
- **Island Sorting**: `SplitBoundariesService` relies on a reference-point containment check instead of area-based containment due to 2026 API method ambiguity.

## Recommendations
1. Centralize the **Plane Geometry** math into `LECG.Core` to avoid duplication.
2. Implement a `CoordinateConverter` service to handle Revit's complex Absolute vs Relative elevation transforms centrally.
3. Add specialized unit tests for `GroupLoopsByIslands` with nested voids.

## Technical Debt to Address
- [ ] Refine `SplitBoundaries` island grouping to use area-based sorting once 2026 API method signatures are fully confirmed via `RevitApiExtractor`.
- [ ] Create a `GeometryPlane` abstraction to encapsulate normal/projection math.
