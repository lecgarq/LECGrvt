## Lessons Learned
- `multi_replace_file_content` can be unstable with Large XAML files; `write_to_file` is safer for full-file rewrites.
- Revit 2026 WPF windows require specific `MinWidth`/`MinHeight` to prevent viewport clipping in high-DPI environments.
- Shared component logic (SelectionControl) significantly reduces view-layer boilerplate.
