## Data Flow

1. **Activation:** User clicks a ribbon button -> `IExternalCommand.Execute` is called.
2. **Initialization:** The command resolves its dependencies and opens a `LecgWindow`.
3. **Logic:** The `ViewModel` interacts with `Services` to process Revit elements inside a transaction.
4. **Feedback:** UI updates via DataBinding; logging handled by `Serilog`.

## Key Patterns
- **Safe Failure Handling:** Centralized via `SafeFailureHandler` and `TransactionService`.
- **Dependency Injection:** Custom bootstrapper in `App.cs` using `SimpleDi` (internal container) and assemblies scanning.
- **Geometric Ops:** Heavy use of `Clipper2` and `geometry3Sharp` for polygon/mesh manipulation.
